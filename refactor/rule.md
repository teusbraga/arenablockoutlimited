# Regras da pasta /refactor

Este diretório serve de guia para **refatoração, melhoria e simplificação de código** do projeto.

Regras obrigatórias:

1. Nenhum arquivo `.md` existente nesta pasta (ou em `done/`) deve ser **apagado**.
2. Quando um documento de diagnóstico/plano for concluído ou for substituído por uma nova versão, ele deve ser **movido para a subpasta `done/`**, não excluído.
3. Novos documentos de diagnóstico/refatoração devem ser criados aqui (raiz de `refactor/`) e, ao final do ciclo, movidos para `done/`.
4. A subpasta `done/` mantém o histórico de documentos já processados.
